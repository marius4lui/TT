# Eigene Produktionsinstallation

Die Produktionsdaten einer einzelnen Installation gehören nicht in die öffentliche Projektbeschreibung. Verwende [SELF_HOSTING.md](SELF_HOSTING.md) für die Einrichtung und [OPERATIONS.md](OPERATIONS.md) für Betrieb und Wiederherstellung.

Halte intern mindestens Account, Workername, D1-ID und Jurisdiktion, öffentliche Origin, Evolution-Version und Instanz, Betreiberkontakte, Backupverfahren und zuletzt geprüfte Releaseversion fest. Secrets separat speichern. Die eigene `wrangler.production.jsonc` wird von Git ignoriert.

Frühere Revisionen dieser Datei enthielten Angaben einer konkreten Installation. Die Git-Historie ist dadurch nicht automatisch bereinigt; siehe [OPEN_SOURCE_READINESS.md](OPEN_SOURCE_READINESS.md).
